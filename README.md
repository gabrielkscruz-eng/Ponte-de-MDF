# 🌉 Ponte de MDF

Projeto educacional de construção de uma ponte estrutural em MDF com foco em engenharia e design estrutural.

## 📋 Sobre o Projeto

Desenvolvimento de um protótipo de ponte em MDF que demonstra princípios fundamentais de engenharia estrutural, resistência de materiais e design de construção.

## 🎯 Objetivos

- ✅ Aplicar conceitos de engenharia estrutural
- ✅ Testar resistência e estabilidade de materiais
- ✅ Documentar processo de construção
- ✅ Validar design através de testes práticos

## 🛠️ Materiais

- **MDF** - Material principal de construção
- Estrutura modular e reutilizável
- Otimizado para resistência máxima
